# LuaJIT validator runtime

These Windows x64 binaries provide the Lua 5.1-compatible interpreter used by
the Content Editor's offline mod validator. They are not used to run the game.

- Version: LuaJIT 2.1.1785763465
- Project: https://luajit.org/
- Copyright: 2005-2026 Mike Pall
- License: MIT; see `LICENSE`

The editor prefers this bundled copy on Windows and continues to support
`MODKIT_LUAJIT` and system installations.
