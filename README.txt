Gen1Recomp Content Editor — portable Windows pack

1. Double-click ContentEditor.bat
2. Project → GAME DATA → Link Recomp (or Import ROM)
3. Project → Open mods\New_PokemonTest (or Create a new mod)
4. Edit → Save

This pack has no ROM cache. Link your Gen1Recomp folder or import a ROM
for full maps/species/playtest. Fixtures work for light authoring.

Full guide: README.md or docs\content-editor.md

Share your work as the mods\<id>\ folder. Do not ship ROM files (.gb)
or data\generated / assets\generated.
