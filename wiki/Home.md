# Gen1Recomp Content Editor

The Content Editor creates and maintains Gen1Recomp mods without requiring
authors to edit generated Lua by hand.

## Start here

- [[Maps]] — view, create, paint, connect, animate, and export maps.
- Open or create a mod from **Project** before editing content.
- Use **Save** to compile editor source into normal Gen1Recomp mod records.

## Portable packages

- Windows: `gen1recomp-content-editor-win64.zip`
- Linux: `gen1recomp-content-editor-linux64.tar.gz`
- macOS: `gen1recomp-content-editor-macos-universal.tar.gz`

Portable packages contain no ROM or ROM-derived cache. Each user links a local
Gen1Recomp checkout or imports their own supported game ROM.
